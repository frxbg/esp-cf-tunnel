## Reload diagnosis

Low advertised stream limits caused missing assets and edge GOAWAY(NO_ERROR)
during live hard reloads. An odd Last-Stream-ID (17 captured) then caused nghttp2
to report a local PROTOCOL_ERROR. A similar parity issue is
[reported in Go](https://github.com/golang/go/issues/80759). The exact private
edge-pool decision is not visible; capacity retirement is inferred.

The fix matches cloudflared's wire capacity while retaining local admission and
heap limits, enables four monitor app contexts and retains original peer/local
diagnostics. No nghttp2 validation was relaxed. Successful reloads establish a
short regression result, not a general uptime guarantee.

## Publication checks

The public source inventory passes the project publication guard and Gitleaks
8.30.1. Real provisioning files, flash backups and private captures were removed
from the workspace before the initial commit. The only Gitleaks suppression is
an inline marker on the fixed synthetic account tag in the RPC test.

Packaging was checked by copying the component ZIP into an independent ESP-IDF
6.1 S3 project and compiling with transport enabled. The monitor no-PSRAM profile
also builds from a clean source-only export. These are compile checks, not new
hardware runs. The component ZIP is generated from canonical Git index bytes,
includes its dependency licenses and public CA roots, and ships with SHA256SUMS.

## Reproduce

See [CONTRIBUTING.md](../CONTRIBUTING.md) for commands and
[the RPC oracle](../tools/rpc_reference/README.md) for its separate requirements.
Checked-in fixture bytes are synthetic. CI does not read device credentials or
connect to a real tunnel.

[build-report.json](build-report.json) and
[monitor-build-report.json](monitor-build-report.json) preserve the measured
development binary inventory. Hashes describe those builds, not a promise of
bit-identical output from another SDK path, Git checkout or build timestamp.

## Remaining validation

- Long soak, multi-client saturation and 100 real task/socket/TLS restart cycles.
- Hardware 10 MiB transfer, precise latency/CPU and fragmentation trends.
- P4 and no-PSRAM runtime, including board/network-interface integration.
- Complete public post-login Unlock/Scan and remote configuration mutation matrix.
- Generic HTTP semantics, deferred inbound backpressure and deterministic TLS fault injection.

No token, private key, reusable password, device-configured binary or private
capture is part of this repository. Public certificates are trust anchors, and
the small RPC `.bin` files are deterministic synthetic test vectors.
