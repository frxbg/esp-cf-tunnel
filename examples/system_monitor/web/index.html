Built-in RGB LED

Waiting

One addressable LED on GPIO 48. Unlock Settings, then choose a color or use a preset.

If the LED stays dark, check the board's RGB / NeoPixel solder jumper. The LED starts off after every restart.

Pins start disabled after every restart. Use only 3.3 V signals. Check your wiring before selecting Output; applying it drives the selected level immediately.
